A responsive CSS demo gallery recreated from the supplied screen recording.

## Included transforms
1. Translate — `translate(60px, -30px)`
2. Rotate — `rotate(360deg)`
3. Scale — `scale(1.5)`
4. Skew — `skew(15deg, 10deg)`
5. Combined — `translateY(-30px) rotate(15deg) scale(1.2)`
6. Auto Animation — `animation: spin 3s linear infinite`

The first five demos animate on hover or keyboard focus. The final demo rotates continuously.

## Run
No dependencies or build step required.

1. Extract the ZIP.
2. Open `index.html` in a modern browser.

Or run:
```bash
python3 -m http.server 8000
```
Then visit http://localhost:8000.

## Files
- `index.html` — demo gallery markup
- `style.css` — visual styling and transform effects
- `script.js` — CSS copy buttons and replay control
- `README.md` — setup guide

## Source fidelity
CSS values that are legible in the video are retained in the snippets. Some source text is small or partially obscured, so this is a complete runnable recreation of the visible examples, not an exact recovery of the original project files.
